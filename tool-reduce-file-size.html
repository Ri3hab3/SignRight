FAQ
Common questions
How do I compress a file to a specific size like 20 MB or 50 MB?

Upload your file, drag the slider to the size you want (or tap a preset such as 20 MB or 50 MB), then click Compress. The tool lowers image quality and resolution step by step until the file fits under your target.

Which file types can I reduce?

PDF, Word (.docx), PowerPoint (.pptx), Excel (.xlsx), and images in JPG, PNG, WebP, BMP and AVIF format. Old binary formats like .doc, .ppt and .xls should be saved in the newer format first.

Will my file always reach the exact size I choose?

Almost always for files that contain photos or scans, which is where most of the size comes from. Files that are mostly text, fonts or video have little to shrink, so the result may land above a very aggressive target. The tool tells you when that happens.

Is my file uploaded anywhere?

No. Compression runs entirely in your browser, so your documents and photos never leave your device. Very large files (hundreds of MB) need enough free memory on your computer, so close other heavy tabs first.

Will text in my PDF still be selectable?

To reach small sizes, PDF pages are re-rendered as compressed images, so text is no longer selectable or searchable afterwards. Keep your original if you need searchable text.

What happens to my Word, PowerPoint and Excel files?

Only the embedded pictures are recompressed. Text, formatting, tables and layout stay exactly as they were, and the file still opens normally in Office.

Is there a file size limit?

You can try files up to 1 GB. Whether a huge file succeeds depends on your device's memory, since everything is processed locally.
