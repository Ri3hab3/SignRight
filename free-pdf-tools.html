FAQ
Common questions
Are these PDF tools really free?

Yes. Every tool on SignRight is free to use with no subscription, no watermark and no limit on how many files you process. We keep the lights on with unobtrusive ads, not paywalls.

Do I need to create an account?

No. You can use every tool without signing up or giving an email address. Just open a tool, drop in your file, and download the result.

Are my files safe and private?

Many of our tools — including sign, compress, reduce file size and remove background — run entirely inside your browser, so your file never leaves your device. Tools that need server processing delete your file shortly after it is handled.

Is there a file size limit?

Most tools handle files well over 100 MB. Because several tools run locally, the practical limit depends on your device's memory rather than an artificial cap.

Do the tools work on mobile?

Yes. Every tool works in modern mobile browsers on iPhone and Android, as well as on Windows, Mac, Chromebook and Linux. Nothing to install.

Can I use the signed or edited files legally?

Electronic signatures are legally recognized in the US under the ESIGN Act and UETA, and in the EU under eIDAS. Our eSign and PDF tools produce standard, shareable PDF files.

Which file formats are supported?

PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), and images in JPG, PNG, WebP and more. Each tool page lists the exact formats it accepts.
